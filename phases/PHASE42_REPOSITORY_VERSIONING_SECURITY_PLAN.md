## الهدف

توفير تاريخ موثوق وقابل للتدقيق لتحديثات المستودعات، وإظهار التغييرات قبل اعتمادها، وإتاحة الرجوع، مع تقليل صلاحيات JavaScript وتحجيم مخاطر SSRF والتنزيلات غير المحدودة.

## حدود التنفيذ

- توسيع `SourceRepositoryManager` و`SourceRepositoryClient` الحاليين؛ لا إنشاء مسار مزامنة موازٍ.
- تخزين snapshot محلي خاص بالتطبيق مع SHA-256، وقت الجلب وآخر تحقق، HTTP status، ETag وLast-Modified، المرجع والـ commit عند توفرهما.
- حفظ المستندات التي تم جلبها ونسخ سكربتات المصادر حسب البصمة، مع حد احتفاظ 20 إصدارًا للمستودع و20 سكربتًا لكل مصدر.
- دعم GitHub Raw pin باستخدام commit SHA كامل من 40 خانة فقط.
- توفير معاينة تغييرات وتطبيق نفس الوثائق التي وافق عليها المستخدم، وتراجع إلى نسخة سابقة واستئناف التحديثات.
- إظهار provenance والتكرار للمراجعة دون حذف أو تعطيل تلقائي.
- حصر QuickJS في قنوات المضيف المطلوبة، وتعطيل `XMLHttpRequest` الأصلي.
- فرض سياسة URL/DNS/redirect/response size/timeouts على مستودعات المصادر وQuickJS وStremio.

## معايير القبول

1. يمكن قراءة SHA-256 ومعلومات التحقق وإصدارات المستودع.
2. يمكن مقارنة تحديث مرشح واعتماده بنفس البايتات التي تمت معاينتها.
3. يمكن الرجوع إلى آخر snapshot محفوظ ثم استئناف التحديث الطبيعي.
4. لا تُقبل روابط محلية أو شبكات خاصة أو تحويلات إلى وجهات محظورة.
5. لا تتجاوز الإضافات قنوات QuickJS الأربع المحددة ولا تستخدم XHR الأصلي.
6. لا تكشف بيانات الاعتماد في metadata أو السجلات أو snapshots.
7. يمر تحليل Flutter والاختبارات المحددة وبناء Release ARM64 في CI.

## خارج النطاق

- اعتبار SHA-256 توقيعًا أو إثباتًا لموثوقية ناشر الإضافة.
- حذف النسخ المتشابهة تلقائيًا.
- ضمان الحماية القطعية من DNS rebinding دون ربط DNS بالـ socket الفعلي.
- تشغيل المجموعة الكاملة من اختبارات Flutter في كل بناء APK.
