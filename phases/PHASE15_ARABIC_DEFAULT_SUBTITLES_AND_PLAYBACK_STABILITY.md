# PHASE 15 — Arabic Default Subtitles & Playback Stability

## الهدف

معالجة المشكلات التي ظهرت في اختبار Phase 14:

- اكتشاف مزوّد جديد يجب ألا يغيّر السيرفر أو الرابط النشط.
- جمع روابط جميع المزوّدين في كتالوج جودة واحد مستقل عن مصدر BetterPlayer الحالي.
- جعل العربية اللغة الافتراضية للترجمة، وإظهارها تلقائيًا عند توفرها.
- الاحتفاظ بملفات الترجمة الخارجية وأسمائها ومصادرها بين جلسات تشغيل العنوان نفسه.

## 1. ثبات مصدر التشغيل

- تحديثات `ProviderScanUpdate` تضيف الروابط إلى كتالوج المصادر فقط.
- لا تستدعي تحديثات المسح `setupDataSource` ولا تغيّر `_activeStreamUrl` أو `_currentProviderCode`.
- أضيف تسجيل تشخيصي `[PlaybackScan][CATALOG_ONLY]` مع تحقق داخلي من بقاء الرابط والمزوّد النشطين دون تغيير أثناء تحديث الكتالوج.
- أزيل التبديل المعتمد على مرور وقت طويل دون ظهور أول إطار؛ بعد 60 ثانية يُسجّل بطء بدء التشغيل فقط، ويبقى المصدر الحالي كما هو.
- يظل الانتقال التلقائي مسموحًا فقط عبر مسار استرداد فشل تشغيل فعلي من BetterPlayer، لإعادة محاولة الرابط أو استخدام رابط بديل عند تلف الرابط/انتهائه. اختيار المزوّد أو الجودة من المستخدم يظل تبديلًا يدويًا.

## 2. كتالوج الجودة الموحد

- يعتمد منتقي الجودة على `PlaybackQualityCatalog` المبني من روابط كل المزوّدين، لا على قائمة `resolutions` الداخلية للمصدر النشط وحده.
- يبقى لكل رابط مصدره واسم مزوّده ورؤوس الطلب وصيغته ووقت انتهاء صلاحيته.
- لا تُدمج روابط مزوّدين مختلفين لمجرد تساوي الدقة؛ تُزال النسخ المطابقة فقط.
- تُعرض مصادر HLS/DASH التكيفية ومساراتها كخيارات منفصلة عن روابط MP4/DASH/HLS الثابتة.
- تحديثات الكتالوج أثناء فتح منتقي الجودة تعيد بناء القائمة دون إعادة تهيئة مشغل الفيديو.

## 3. العربية كلغة ترجمة افتراضية

- أضيف تفضيل افتراضي `ar` في `SettingsProvider` ومفتاح تفضيل جديد `default_subtitle_v3`.
- تُرحّل القيمة الافتراضية الإنجليزية القديمة إلى العربية، مع الاحتفاظ بالاختيارات غير الإنجليزية المحفوظة وباختيار Any الصريح.
- عند إعداد ترجمات أي مزوّد، يُعلّم أول مسار يطابق اللغة المفضلة `selectedByDefault`.
- إذا لم تتوفر ترجمة عربية من المزوّد النشط، يبدأ بحث خارجي تلقائي بعد إعداد مصدر الفيديو؛ لا ينتظر البحث قبل بدء المشاهدة.
- يرتب البحث النتائج بحسب اللغة المفضلة، ويجرب تنزيل المرشحين العرب بالتتابع حتى ينجح أحدها أو تنتهي القائمة.
- لا يعني التفضيل ضمان وجود ترجمة عربية لكل عنوان؛ عند عدم توفر ملف مناسب تبقى بقية اللغات متاحة ولا تتوقف المشاهدة.

## 4. حفظ واستعادة ملفات الترجمة

- أضيف `SubtitlePlaybackStore` لحفظ ملف WebVTT محليًا مع بيان اللغة واسم العرض والمزوّد والتنسيق والإصدار وعلامة HI.
- تُحفظ الملفات لكل معرّف فيلم/حلقة في مساحة التطبيق، مستقلة عن صلاحية رابط الفيديو المؤقت.
- تُستعاد بيانات الترجمة المحلية قبل إنشاء مصدر BetterPlayer الأول، حتى لا تختفي أسماء اللغات عند إعادة استخدام رابط فيديو محفوظ.
- تبقى الترجمات الخارجية/المحلية مستقلة عند تغيير سيرفر الفيديو، بينما تُستبدل ترجمات السيرفر الشبكية بترجمات السيرفر الذي اختاره المستخدم لتجنب تمرير روابط ترجمة قديمة مع المصدر الجديد.
- تُطبّع رموز اللغة مثل `ara` و`Arabic` إلى `ar`، و`eng` و`English` إلى `en`.
- يتعرف منتقي الترجمة على مصدر الملف المحلي من لاحقة الاسم مثل `Arabic · OpenSubtitles`، ويفصل اسم اللغة عن اسم المزوّد عند التعريب والعرض.

## 5. الاختبارات المضافة أو المحدّثة

- `test/quality_catalog_test.dart`: جميع المزوّدين، الدقات غير القياسية، المصادر تحت Unified Sources، الروابط المتساوية بالدقة، والروابط المنتهية.
- `test/provider_background_scan_test.dart`: الاحتفاظ بنتائج الطلبات التي بدأت قبل اكتمال هدف الدقات.
- `test/subtitle_playback_store_test.dart`: حفظ/استعادة WebVTT وبيانات العربية والمزوّد، بما في ذلك رمز اللغة `ara`.
- `test/settings_subtitle_language_migration_test.dart`: ترحيل التفضيل القديم إلى العربية والاحتفاظ بالاختيارات المحفوظة.
- `test/subtitle_options_test.dart` و`test/language_names_test.dart`: استعادة اسم المزوّد وتعريب اسم اللغة للملفات المحلية.
- `test/external_subtitle_service_test.dart`: البحث الخارجي وطلبات OpenSubtitles المتوازية.

## 6. مفاتيح API والخصوصية

- لا تضع مفاتيح OpenSubtitles أو SubDL الخاصة في `.env` المضمّن داخل APK؛ أي قيمة عميل موجودة في APK قابلة للاستخراج.
- يظل `ARABICSUBS_PROXY_URL` مجرد رابط إلى خادم المستخدم؛ يجب أن يبقى مفتاح ArabicSubs الخاص في ذلك الخادم، لا داخل التطبيق.
- ترك قيم المفاتيح الاختيارية فارغة لا يمنع استخدام OpenSubtitles legacy وSubSource وScraper API عندما تكون متاحة.

## 7. حالة التحقق

- تمت مراجعة مسارات التغيير والمطابقة يدويًا، والتحقق من وجود ملفات الاختبارات وتقرير المرحلة في المشروع.
- لم يتم تشغيل `flutter test` أو `flutter build apk --release` في بيئة إعداد هذه المرحلة لعدم توفر Flutter/Dart SDK فيها.
- لذلك لا يُدّعى نجاح بناء Android أو نجاح تشغيل فعلي على جهاز؛ يلزم تأكيد ذلك عبر GitHub Actions والاختبار على الجهاز.
